## 安装

1. 下载 `.dmg` 后双击打开，把应用拖进「应用程序」文件夹。
2. 应用未经 Apple 公证，首次打开会提示「无法验证开发者」。到「系统设置 → 隐私与安全性」，在下方点「仍要打开」，再确认一次即可。
3. 如果提示「文件已损坏」，在终端执行下面这行再打开：

```bash
xattr -dr com.apple.quarantine /Applications/防内耗机器.app
```

应用内已经带了独立的 Python 运行时，**不需要另外安装 Python**，装到任何一台 Mac 上都能直接运行。
